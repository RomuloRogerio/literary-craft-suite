# Literary Craft Suite

Plugin para Claude Code focado em crítica literária erudita, análise de ludonarrativa em livros-jogos e eliminação de escrita robótica de IA.

## Comandos Disponíveis:
- `/critique [texto]` - Triagem por gênero e análise cirúrgica em 4 blocos.
- `/humanize [texto]` - Reescrita purgada de clichês e simetrias de LLM.
- `/audit-branching [seção]` - Auditoria de opções e mecânicas em livros-jogos.
